HÓPVERKEFNI 1:

Keyrsla verkefnis:

Fyrst þarf að setja upp nauðsynslega pakka npm install, síðan til
að ræsa verkefnið skal nota npm run dev og til að keyra stylelint skal nota npm run lint.

Uppsetning verkefnis:

Verkefninu er skipt niður í möppur sem að fara eftir hlutverki skráa.

sidur/ Inniheldur síðurnar okkar, fyrir utan index.HTML (Forsíðan)
styles/ Inniheldur CSS/Sass skrár fyrir hverja síðu fyrir sig
myndir/ Inniheldur allar myndir sem að notað var í verkefninu
package.json / Inniheldur upplýsingar um verkefnið, það er að segja npm skipanir og nauðsynleg verkfæri.
package-lock.json/ Inniheldur upplýsingar um uppsetta pakka
.gitignore/ Inniheldur hvaða skrá og möppur Git á að hunsa
